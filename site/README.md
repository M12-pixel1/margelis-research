# Generated site and the canonical host contract

Everything under `site/` is generated by `python tools/publish.py build`; do not
edit it by hand. `site/research/` is what both hosts serve:

- the GitHub Pages mirror deploys the whole `site/` directory (`.github/workflows/pages.yml`);
- the canonical host, `https://rupestelisholding.com/research/`, receives `site/research/`
  through a private deploy script kept outside this repository.

Contract that the canonical deploy must satisfy (checked by `publish.py probe`
and by the weekly `drift-check`):

- `site/research/` is copied verbatim to `/research/` with paths unchanged;
  `v<version>/` folders and their `SHA256SUMS` are preserved and nothing is deleted,
  so every earlier version stays byte-identical.
- Served types: HTML as `text/html`, PDF as `application/pdf`, Markdown as
  `text/markdown`, `feed.xml` as `application/atom+xml` or `application/xml`,
  `index.json` as `application/json`.
- The pages contain no JavaScript, so the host's `Content-Security-Policy` with
  `script-src 'none'` is compatible; the current host also sends `X-Frame-Options: DENY`.
- `/research/001` (no trailing slash) redirects to `/research/001/`.

After a deploy, `python tools/publish.py probe 001` must report the canonical
page as `LIVE` with the PDF digest and the License row matching the repository.
